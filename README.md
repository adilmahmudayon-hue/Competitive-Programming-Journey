## ▶️ Running the Solutions

Most solutions are standalone C++ programs.

For example:

```bash
g++ solution.cpp -o solution
```

Then run:

### Windows

```bash
solution.exe
```

### Linux / macOS

```bash
./solution
```

Some problems may require input from standard input according to the original problem statement.
